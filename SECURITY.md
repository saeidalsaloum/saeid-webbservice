# Security Policy

## Reporting a Vulnerability

If you find a security issue in this repository or the public website, open a GitHub issue or pull request with a concise description of the problem and the affected file or page.

Do not include secrets, credentials, tokens, private keys, personal data, customer data, personal identity numbers, legal case material, or private business records in any report.

If a report requires sensitive details, first contact the repository owner through a private channel already known to you. Do not publish sensitive details in a public issue.

## Scope

This repository contains a static GitHub Pages website. It should not contain backend systems, databases, customer records, payment flows, private APIs, forms, analytics exports, or operational secrets.

Relevant security concerns include accidental secret exposure, unsafe third-party scripts, broken deployment assumptions, privacy-impacting tracking, and changes that make the static site collect or expose personal data.

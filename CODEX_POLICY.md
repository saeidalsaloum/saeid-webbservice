# Codex Usage Policy

Codex may be used in this repository for static website maintenance, documentation, governance, and non-destructive validation.

## Safe Uses

- Review repository structure and GitHub Pages deployability.
- Update concise documentation and governance files.
- Make requested HTML or CSS changes to the static site.
- Run local validation commands.
- Prepare pull requests when explicitly requested by the owner.

## Boundaries

Codex must work only inside this repository. It must not import content from other projects, mailboxes, private files, analytics tools, customer records, or external systems.

Codex must not add secrets, credentials, customer data, personal identity numbers, private legal material, or private business records.

## Website Safety

The site must remain deployable as static GitHub Pages content. Codex should avoid adding build systems, package managers, external scripts, forms, tracking, or backend assumptions unless the owner explicitly approves the change.

## GitHub Operations

Codex may create branches, commits, pushes, or pull requests only when the owner explicitly asks for those actions. Pull requests should default to Draft unless the owner requests otherwise.

## Review Standard

Before completing work, Codex should report changed files, validation performed, whether public website content changed, and any remaining manual checks.
